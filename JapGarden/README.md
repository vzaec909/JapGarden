# ⛩️ JapGarden — генератор сада Рёандзи

Программа для расчёта положения камней в саду Рёандзи
согласно числам Фибоначчи и золотому сечению.

## Возможности

- 🌸 **Десктоп (tkinter)** — классический интерфейс с сохранением PNG
- 🌐 **Веб (HTML/CSS/JS)** — браузерная версия с пресетами
- 🔌 **REST API (FastAPI)** — для мобильных приложений (Kotlin и др.)
- 📐 **Золотая сетка** — переключатель для архитекторов
- 🎲 **Случайный сад** — генерация в один клик
- ⛩️ **Пресеты** — классические композиции

## Установка

```bash
git clone https://github.com/your-username/JapGarden.git
cd JapGarden
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

pip install -r requirements.txt
